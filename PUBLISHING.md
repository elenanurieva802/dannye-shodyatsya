# Как менять и публиковать сайт

Рабочий адрес: https://vibe-seller.ru. Репозиторий — источник актуальной версии.

## Правки

1. Перед работой обновите локальную ветку `main` из GitHub.
2. Создайте отдельную ветку, например `update-contacts`.
3. Внесите правки в `index.html` и проверьте страницу в браузере. Сейчас весь сайт находится в этом файле.
4. Сохраните изменения коммитом, отправьте ветку на GitHub и создайте Pull request в `main`.
5. Просмотрите изменения вместе с партнёром и объедините Pull request кнопкой Merge.

Небольшую правку можно сделать через редактор GitHub: откройте `index.html`, нажмите карандаш, при сохранении выберите новую ветку и создайте Pull request. Не загружайте ZIP вместо исходных файлов.

## Публикация

1. Откройте **Actions → Deploy website → Run workflow**.
2. Оставьте ветку **main** и операцию **deploy**.
3. Нажмите **Run workflow** и дождитесь зелёной отметки.
4. Откройте https://vibe-seller.ru, при необходимости обновите страницу без кэша (`Ctrl+F5`).

Публикуется коммит `main`, выбранный на момент запуска. Изменения в GitHub сами по себе сайт не обновляют. Запуск из другой ветки пропускается. Публиковать могут пользователи с правом записи в репозиторий, включая владельца.

## Возврат предыдущей версии

В том же окне выберите **main** и операцию **rollback**. После успешного запуска предыдущая версия снова появится на сайте. Повторный rollback переключает между двумя последними опубликованными версиями. История GitHub при этом не меняется: исправьте `main` перед следующей публикацией.

Каждая выкладка хранится отдельной папкой на сервере. Переключение происходит целиком; сервер проверяет контрольную сумму ответа и при ошибке возвращает прежнюю версию. Успешный workflow дополнительно проверяет сайт по публичному HTTPS и перенаправление с `www`.

## Границы текущей настройки

Публикуется только `index.html`. Стили и JavaScript сейчас встроены в этот файл. Если добавите отдельные изображения, CSS или другие файлы, сначала расширьте обработчик публикации на сервере.

Демо использует вымышленные данные. Контактная форма открывает почтовое приложение и не отправляет заявки на сервер.

Секреты `VIBE_DEPLOY_KEY` и `VIBE_KNOWN_HOSTS` хранятся в GitHub Actions Secrets. Не добавляйте ключи в файлы или переписку. Ключ публикации даёт только команды `deploy <SHA>` и `rollback` от пользователя `vibe-deploy`, без sudo и произвольных SSH-команд. Сервер принимает новые коммиты, входящие в `main`.
