# Данные сходятся

Одностраничный сайт об автоматизации процессов торговых компаний с помощью ИИ.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

## GitHub Pages

В настройках репозитория откройте Settings → Pages, выберите Deploy from a branch, ветку main и папку / (root).

## Возможности

- Адаптивная верстка.
- Переключение демонстрационных ролей на вымышленных данных.
- Скачивание примера CSV.
- Раскрывающиеся ответы на вопросы.
- Подготовка письма через почтовое приложение посетителя.

Демонстрация содержит заранее подготовленные ответы и не подключена к модели ИИ или данным компании. Форма не отправляет заявку на сервер и не хранит данные.
